# Contributing

Thank you for considering contributing!  This project is a simple Nuxt 3 application and contributions are welcome.

## Setup

1. Install [Node.js](https://nodejs.org/) (18 or later is recommended).
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

The app will run on `http://localhost:3000`.

## Formatting and Linting

ESLint is used for code quality.  Run it with:

```bash
npx eslint . --ext .ts,.vue
```

Format your code with Prettier if you have it installed.

## Branches and Commits

- Create feature branches using `feature/<short-description>` or `fix/<short-description>`.
- Follow [Conventional Commits](https://www.conventionalcommits.org/) for commit messages.

## Tests

This project currently has no automated tests.  Verify your changes by running the development server and inspecting the site.
